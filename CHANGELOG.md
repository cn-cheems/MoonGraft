# Changelog

## 0.1.0 — initial repository milestone (unpublished)

- Local Git template creation, pinned source records, target revision checks,
  upgrade planning and verified acceptance for subsequent upgrades.
- Existing-project linking with a local customization report, and local
  descendant discovery with pinned SHAs for branches and tags.
- Batch preparation of independent Git-template upgrades with verified
  candidates, resumable review plans and a machine-readable status report.
- Strict batch-report CI gate and policy-checked batch preparation that
  isolates project failures and retains rejected plans for review.
- Verified local source relocation, read-only whole-batch verification, and
  version 2 manifests with per-project policies enforced alongside common rules.
- Captured batch inputs and policy evidence, all-candidate acceptance into new
  source records, and retry manifests preserving failed projects' pinned inputs.
- Batch acceptance uses a distinct source filename for the `acceptance` project ID.
- Explicit file moves that carry local customizations across template paths and
  preserve conflict review, policy checks, and exact rollback.
- Bounded changed-window diffs for long text files with localized edits.
- Versioned literal template rendering with canonical parameters and exact
  Git baseline replay across project creation, planning, and adoption.
- Explicit parameter migrations with validated renames, defaults and drops,
  recorded in the plan and replayed during adoption.
- Opt-in JSON object merging with exact number spelling, strict duplicate-key
  rejection, atomic arrays, and field-level conflict pointers.
- Exact remote branch and tag pinning from a configured Git remote, with
  retained local commits for offline plan replay after a ref moves.
- Unified upgrade rules combine parameter migrations, file moves, and JSON
  merging in one plan. Batch manifest v3 captures each project's rules and
  policy for verification and retry.
- Historical template adoption case with a disclosed compatibility recipe,
  whole-output checks, business regression tests and revision-bound CI evidence.

- Rendered-template provenance, immutable file trees and directory-level planning.
- Conservative text merging with exact byte/newline preservation and explicit
  binary, addition, deletion and overlapping-edit conflicts.
- Atomic review decisions, plan-bound batch reviews and guarded refresh.
- Deterministic archives, content-free drift/output previews and decision reports.
- Growth/deletion/binary budgets, protected paths and policy-checked export.
- Complete candidate export, verified partial-write recovery, read-only validation
  and guarded rollback with the original template baseline.
- Real public CI-file fixture with disclosed local derivatives and a documented
  independent consumer executed against a local package archive.
- Formatting/interface checks, strict portable tests, actual native CLI tests and
  package consumer execution in the cross-OS CI workflow.

This is a local-workflow alpha. Remote candidate listing and external renderer
integration remain future work. See README for input limits and platform boundaries.
